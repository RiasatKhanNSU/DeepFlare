DeepFlare: Weakly Supervised Cross-Modality Translation and Segmentation
# DeepFlare Dataset
The DeepFlare dataset contains raw and preprocessed immunofluorescence/IHC images used in this study.
## Dataset Source

The raw images are derived from the public BC-DeepLIIF dataset.

## Dataset Organization

After downloading, place the files as follows:

```text
data/
├── raw_images/
│   └── images from CSE499/DATASET/Dataset/
│
└── preprocessed_images/
    └── images from CSE499/Immunofluorescence images/Preprocessing/
## Dataset Download

The raw and preprocessed DeepFlare dataset can be accessed from the following Google Drive link:

[Download DeepFlare Dataset from Google Drive](https://drive.google.com/drive/folders/18QMJ1l2kU_rFZ2ycN5Rs24GPkXUjtNVG?usp=sharing)
